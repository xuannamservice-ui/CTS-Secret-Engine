# CTS Simulation & Creative Architecture Skill

Use this skill when the user asks to design, simulate, optimize, or architect a complex system, simulation model, interactive visual technology, or algorithmic framework.

## Workflow
1. **Model & Problem Formulation**:
   - Define state variables, constraints, objective functions, and dynamics clearly.
   - Choose deterministic, stochastic, or hybrid simulation strategies appropriate for the domain.
2. **Modular Implementation**:
   - Separate core simulation/engine logic from visualization, CLI/UI controls, and I/O.
   - Ensure reproducible random seeds, vectorized operations (NumPy/PyTorch when applicable), and clear telemetry hooks.
3. **Empirical Verification & Visualization**:
   - Run sanity checks, boundary condition tests, and convergence benchmarks before reporting results.
   - Provide structured tables, metrics, or interactive HTML/canvas artifacts so the user can inspect simulation outcomes directly.
